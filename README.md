Одностраничное приглашение по вашим референсам: светлая основа, жемчуг, ч/б фото, Cormorant Infant, две даты и палитры дресс-кода.

- 08.07.2027 — праздник для всех гостей; сбор в 17:00 по Москве.
- Ночёвка с 8 на 9 июля — для желающих.

## Бесплатная публикация через GitHub Actions

1. Создайте **публичный** репозиторий, например `alina-dmitry-wedding`, с основной веткой `main`.
2. Загрузите содержимое этой папки в корень репозитория. Обязательно включите скрытую папку `.github`: в ней workflow публикации. `index.html` остаётся внутри `dist`.
3. Откройте **Settings → Pages → Build and deployment → Source → GitHub Actions**.
4. Откройте **Actions → Publish wedding invitation → Run workflow → main → Run workflow**. Последующие коммиты в `main` запускают публикацию автоматически.
5. После зелёного запуска ссылка появится в **Settings → Pages** и в summary workflow. GitHub может публиковать страницу несколько минут.
6. QR-код появится по адресу `<ссылка-сайта>/qr.html`, а также в артефакте **wedding-invitation-qr** внизу страницы запуска Actions. Есть PNG, SVG и файл с закодированным адресом.

Адрес определяется самим GitHub Pages через `actions/configure-pages`. Workflow генерирует QR именно для этого адреса, включая путь репозитория. Указывать токен, оплачивать хостинг и покупать домен не нужно. QR статический, не использует платные сокращатели и не имеет срока действия; он работает, пока доступен сам сайт по этому адресу.

Если Source ещё не настроен и запуск завершился ошибкой configure-pages: выполните шаг 3 и перезапустите workflow. Владелец репозитория должен иметь право включать Pages.

### Через Git, если скрытая папка не загружается в браузере

Из корня проекта, подставив ваш логин и существующий репозиторий:

```bash
git init -b main
git add .
git commit -m "Create wedding invitation"
git remote add origin https://github.com/YOUR_LOGIN/alina-dmitry-wedding.git
git push -u origin main
```

Git попросит обычную авторизацию GitHub. Не публикуйте личные токены в файлах или чате.

## Как менять сайт

- `dist/index.html` — тексты, блоки, программа.
- `dist/site-config.js` — адрес, карты, цвета, необязательные ссылки анкеты и связи.
- `dist/styles.css` — оформление и мобильная версия.
- `dist/assets/couple.jpg` — выбранная вами ч/б фотография.
- `.github/workflows/deploy.yml` — проверка, публикация и генерация QR.

Время церемонии и банкета не придумано: в программе указаны только подтверждённые 17:00 и порядок событий. Адрес площадки проверен на официальном сайте: https://marinohall.com/peterhof. Перед рассылкой сверяйте его с договором.

## Ответы гостей

По умолчанию анкета работает **без сервера и базы данных**: она готовит сообщение, которое гость должен отправить Алине или Дмитрию в личный чат. На поддерживаемых телефонах можно открыть системное меню отправки; в остальных браузерах — скопировать ответ. Сайт не показывает ложное подтверждение получения ответа и не сохраняет ответы в публичный репозиторий.

Чтобы получать ответы в Яндекс/Google Форму, создайте личную форму и вставьте её публичную ссылку в `rsvpFormUrl` в `dist/site-config.js`. Тогда вместо подготовки сообщения будет кнопка перехода в вашу анкету. Для ссылки на ваш Telegram заполните `contactUrl`. Секреты в конфигурацию добавлять нельзя.

## Локальный просмотр и проверки

Node.js 20+ нужен только для тестов и генерации QR; сам сайт работает без сборки и установки npm-пакетов.

```bash
node --test tests/site.test.cjs
python -m http.server 8000 --directory dist
```

Откройте http://localhost:8000. Не используйте открытие `index.html` через `file://`: лучше локальный сервер.

Чтобы вручную обновить QR для своего постоянного адреса:

```bash
node scripts/generate-qr.cjs https://YOUR_LOGIN.github.io/alina-dmitry-wedding/
```

Эта команда заменяет `dist/qr/` и canonical/og:url в HTML на выбранный адрес. GitHub Actions выполняет её автоматически перед каждой публикацией.

## Перед печатью

Откройте опубликованный сайт с телефона, проверьте обе даты, время, маршрут и ответ гостя. Скачайте SVG с `/qr.html`, вставьте в приглашение размером около 25–30 мм, сохранив белое поле вокруг. Сначала напечатайте один экземпляр и проверьте сканирование. При переносе сайта на другой адрес понадобится новый QR.
