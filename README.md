# Дмитрий и Алина · свадьба 7–8 июля 2027

Одностраничное приглашение по авторскому макету. Статические HTML/CSS/JS, локальные шрифты и оригинальные фотографии, адаптация для телефона, планшета и компьютера. Установка зависимостей не требуется.

## Обновить существующий GitHub Pages

1. Распакуйте архив.
2. Загрузите папку `dist` в корень существующего репозитория через **Add file → Upload files**. Подтвердите замену существующих файлов.
3. Обязательно загрузите также `tests`, `scripts`, `.github` и файлы документации из архива. В новом макете изменились времена событий, поэтому тесты предыдущей версии тоже должны быть заменены. Изменённый workflow запускает все проверки.
4. Сделайте **Commit changes** в `main`. Actions автоматически проверит проект, сгенерирует QR для действительного адреса Pages и опубликует обновление.
5. Дождитесь зелёного статуса. Адрес `https://dimab5.github.io/svadba-invite/` и ранее напечатанный QR сохраняются.

Если создаёте репозиторий заново: он должен быть Public для GitHub Free; выберите **Settings → Pages → Source → GitHub Actions**. workflow уже находится в `.github/workflows/deploy.yml`.

## Что редактировать

- `dist/index.html` — тексты, календарь, программа и структура.
- `dist/styles-v11.css` — оформление и адаптация.
- `dist/site-config.js` — палитры, ссылки, подключение анкеты.
- `dist/assets/design/` — предоставленные фотографии и элементы оформления.
- `FORM-SETUP.md` — сохранение ответов через Formspree или Яндекс Формы.
- `DESIGN-ASSETS.md` — описание переноса макета.

Код анкеты без настроенного сервиса только готовит сообщение для отправки. Ответы не сохраняются в репозитории или на хостинге автоматически.

## Проверить локально

Нужен Node.js 20 или новее:

```sh
node --test tests/site.test.cjs tests/form.test.cjs
```

Для просмотра запустите любой статический HTTP-сервер из `dist`. Например, при наличии Python:

```sh
python -m http.server 8000 --directory dist
```

Откройте `http://localhost:8000/`.

## QR

`qr.html` содержит ссылки для скачивания PNG/SVG. QR статический, без платной подписки на генератор. Он кодирует URL сайта. Редактирование содержимого по тому же URL не требует печатать QR заново.

Генерация вручную для текущего адреса:

```sh
SITE_URL='https://dimab5.github.io/svadba-invite/' node scripts/generate-qr.cjs
```

В PowerShell:

```powershell
$env:SITE_URL = 'https://dimab5.github.io/svadba-invite/'
node scripts/generate-qr.cjs
```

Исходники не содержат паролей, закрытых API-ключей или ответов гостей.
